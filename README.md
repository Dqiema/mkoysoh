# mkoy. — Школьная экосистема 🏫

**mkoy.** — это полноценное одностраничное веб-приложение (SPA) для учеников, работающее прямо в браузере. Приложение не требует сервера, базы данных или сборки. Все данные сохраняются локально, а общение между устройствами происходит в реальном времени через открытый WebSocket-сервер.

Проект написан на чистом **HTML, CSS и JavaScript** без использования фреймворков (React, Vue, Tailwind и т.д.).

## ✨ Основные возможности

*   **Профили и кастомизация:**
    *   Регистрация и вход с восстановлением пароля.
    *   Смена ника, пароля и добавление описания профиля.
    *   Установка аватара (фото, эмодзи или первая буква ника).
    *   **20 видов обводки** для аватара (градиенты, свечения, пунктиры).
    *   Просмотр карточек других пользователей.
*   **Чаты и общение:**
    *   Общий чат школы и отдельные чаты для каждого класса (с 5 по 11).
    *   Личные сообщения (ЛС) с поиском друзей по нику или сканированием QR-кода.
    *   Возможность **закреплять** важные чаты в списке.
    *   Отправка текста, эмодзи, кастомных стикеров, фото, GIF и **голосовых сообщений**.
    *   Индикатор «Печатает...» и счетчик онлайна в чате.
    *   Подарки в виде внутренней валюты (Буpoint) прямо в ЛС.
*   **Школа и контент:**
    *   Электронный дневник (ссылка на Дневник.ру).
    *   Расписание в виде фотографий (с возможностью зума и скачивания).
    *   Новости школы с возможностью комментировать и делать репосты.
    *   Система квестов (заданий) с наградами.
*   **Геймификация и фишки:**
    *   Внутренняя валюта **Буpoint (Б.)** и магазин (покупка Премиум-статуса).
    *   **Питомец:** интерактивный монстрик, которого можно перетаскивать по экрану. Он издает эмоции, общается (генерирует фразы) и грустнеет, если потрясти телефон.
    *   Смена тем оформления (6 тем, включая светлую и цветные).
    *   Смена звуковых паков (5 вариантов синтезированных звуков).
    *   Версия для ПК (адаптивный интерфейс с боковой панелью).

## 🛠 Технологии

*   **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), Vanilla JavaScript (ES6).
*   **Синхронизация:** [ntfy.sh](https://ntfy.sh/) (публичный WebSocket-сервер для обмена сообщениями в реальном времени).
*   **QR-коды:** `qrcodejs` (генерация) и `html5-qrcode` (сканирование камерой).
*   **Хранение данных:** `localStorage` (аккаунты, сообщения, настройки, кэш).

## 🚀 Как запустить локально

Так как это SPA без сборки, вам достаточно открыть файл `index.html` в браузере.

1. Скачайте репозиторий.
2. Найдите файл `index.html`.
3. Дважды кликните по нему (или откройте через браузер).
4. *Примечание:* Камера для сканирования QR-кода может не работать при открытии через `file://`. Для тестирования камеры используйте локальный сервер (например, расширение Live Server в VS Code) или GitHub Pages.

## 🌐 Как задеплоить на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите файл `index.html` в корень репозитория.
3. Перейдите в **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите **Source**: `Deploy from a branch`.
5. Выберите ветку **Branch**: `main` (или `master`) и папку `/ (root)`.
6. Нажмите **Save**.
7. Через 1-2 минуты ваш сайт будет доступен по адресу `https://ваш-ник.github.io/название-репозитория/`.

## 🔐 Роли и статусы

В приложении есть скрытые роли, которые дают расширенные права:

*   **Владелец:** При регистрации с ником `dqiema` или `rinaт` (или если пароль начинается с `mkoyvladel`) аккаунт получает статус владельца. Владельцы могут создавать/удалять новости, квесты и загружать расписание для всех классов. У них есть безлимитный баланс Буpoint.
*   **Учитель:** Имеет соответствующую приписку в профиле и чатах. Может отправлять фотографии в чаты.
*   **Premium:** Покупается в магазине за Буpoint. Дает золотую приписку в никнейме.

## ⚠️ Важно знать

*   **Синхронизация:** Для того чтобы переписываться с другого устройства, вам нужно находиться в одном «канале». По умолчанию в коде прописан общий канал `mkoy_chat_v6`. Все пользователи, открывшие приложение, автоматически попадают в него.
*   **Безопасность:** Поскольку используется публичный сервер `ntfy.sh`, не отправляйте через приложение реальные пароли, номера карт или другие конфиденциальные данные. Это учебный/демонстрационный проект.
*   **Очистка кэша:** Все данные (включая аккаунты и переписки) хранятся в `localStorage` вашего браузера. Если вы очистите кэш сайта, ваши локальные данные будут утеряны (но сообщения из сети могут подгрузиться заново).
